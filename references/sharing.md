# 分享与账号隔离

对 Clash Verge/Mihomo 用户，优先提供一份客户端 YAML：含 Reality、Hysteria2、AnyTLS，保留 UDP443→Hysteria2 的规则。收件人安装客户端、导入并使用规则模式即可。文件含访问凭据，按密码文件处理，通过私密渠道发送。

对 Shadowrocket 等用户，通常提供 VLESS Reality 分享链接或二维码最方便；还需单独导入 Hysteria2 并在该客户端设置 UDP443 分流，不能声称单个 Reality 二维码包含完整规则。具体协议/证书指纹字段支持以目标客户端实际导入及连接为准。

`export_share.py` 只做本地离线编码；不通过第三方二维码 API。没有安装 `qrcode` 时仅导出链接，并明确二维码未生成。可以在隔离 Python 环境安装 qrcode[pil] 后重试。

每个接收方应有独立 Reality UUID、Hysteria2 密码、AnyTLS 密码。Reality 服务端密钥和 TLS 证书属于服务器身份，可共用；HY2 Salamander 参数是全局混淆参数，不能代替独立认证密码。

当前部署脚本只管理一套默认用户。用户要求真正分享时，给接收方增加三个协议的独立用户条目，备份并验证服务端配置，再生成只含其身份的配置；撤销时只删除其条目。无需重建机器或分享 SSH。新增/删除用户的配置改动应在已授权分享范围内实施，服务 reload/restart 后复测；不要用默认用户文件声称实现了独立权限。

人数少时无需开放订阅 HTTP 端口。需要自动更新时，再按用户明确需求设计 HTTPS、不可猜测的订阅 token、访问控制和凭据轮换；不默认公开托管配置。除非明确要求，本技能不向别人发送任何消息或文件。
